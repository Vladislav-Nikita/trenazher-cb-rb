# База знаний: аттестат специалиста рынка ценных бумаг (РБ)

Каркас для ответов агента по материалам книги *«вся книга с нумерацией январь 2025.pdf»* (программа повышения квалификации 1–2 категории).

## Как пользоваться

1. Сначала открой [`ontology.md`](ontology.md) — карта сущностей и связей.
2. По карте открой **1–2** файла из [`topics/`](topics/).
3. При необходимости уточни раздел/страницу в [`program-index.md`](program-index.md) и норму в [`npa-index.md`](npa-index.md).
4. PDF книги — только для точечной проверки, не читай целиком на каждый вопрос.

## Захват пробелов (обязательно для агентов)

Если ответ **не** находится быстро в `ontology` + 1–2 карточках (или найден только после охоты по PDF):

1. **Не оставляй дыру.** После ответа (или сразу после нахождения факта в PDF) **создай или допиши** карточку в `topics/`.
2. Добавь/обнови строку в таблице «Куда идти» в [`ontology.md`](ontology.md).
3. При новой теме раздела программы — укажи карточку в [`program-index.md`](program-index.md).
4. Новые статьи НПА из книги — строка в [`npa-index.md`](npa-index.md).
5. В карточке — сжатый факт + «не путать» + ориентир страницы книги/PDF и НПА **как в книге**. Не выдумывай нормы.

Цель: следующий агент читает карточку за секунды, а не снова парсит PDF.

### Шаблон новой карточки `topics/<slug>.md`

```markdown
# <Название темы>

**Разделы книги:** программа A/B §… (огл. стр. …).  
**См. также:** `….md`

## Определение
…

## Ключевые различия / не путать
| … | … |

## Типичный вопрос экзамена
> …
**Ответ-каркас:** …

## Источники в книге
- ~печ. … / PDF ~…; НПА …
```

## Состав

| Файл | Назначение |
|------|------------|
| `ontology.md` | Кто есть кто, совмещения, типичные путаницы, маршрутизация |
| `program-index.md` | Оглавление двух программ + страницы книги |
| `npa-index.md` | НПА и статьи, **как они названы в книге** |
| `topics/*.md` | Тематические карточки (в т.ч. дописанные по ходу вопросов) |

## Ограничения каркаса

- Источник истины: книга в этой папке. Не подтягивать «общие знания» РФ/ЕС вместо норм РБ.
- Рабочие копии текстов НПА с pravo.by (ЗОРЦБ, ЗХО, Закон № 213-З, Указ № 277, КоАП, ГК) лежат в `_work/npa/*.txt`, постраничный текст книги — в `_work/book_pages/NNN.txt` (номер = страница PDF; печатная ≈ PDF − 30). Для поиска используй grep, целиком не читай.
- Банк вопросов: `questions/*.json`. После правок запусти `python scripts/shuffle_options.py` (новые вопросы пишутся с правильным вариантом под номером «1»), затем `python scripts/render_review.py`.
- Презентации (акции, инвестфонды, производные, секьюритизация) пока только отмечены в индексе; карточек по ним нет — при вопросе по ним создай карточку по шаблону выше.
