# Корпоративное управление (ХО, АО)

**Разделы книги:** программа B §9 (огл. стр. 229; PDF 259–295).  
**См. также:** `deals-registration.md` (акции ЗАО, ст. 77–78 ЗХО), `depositary.md` (депозитарий эмитента).  
**Вопросы:** `questions/d09_corporate_governance.json`

## Определения

- **ХО** — коммерческая организация, УФ которой разделен на доли (акции) участников. Формы: ОАО, ЗАО, ООО, ОДО (полное товарищество — не ХО).
- **Зависимое ХО** — другое ХО имеет 20%+ голосов; зависимое не вправе иметь/приобретать доли (акции) «основного».
- **АО** — УФ разделен на акции **одинаковой номинальной стоимости** (ст. 96 ГК). Акция — именная, бездокументарная; на предъявителя и ордерные — не допускаются.
- **Учредительный документ АО** — устав. Договор о создании АО — не учредительный документ.

## Ключевые числа

| Что | Норма |
|-----|-------|
| Мин. УФ | ОАО 400 б.в., ЗАО 100 б.в. |
| Число акционеров ЗАО | закон не ограничивает; устав может (превышение → реорганизация/изменение вида за 1 год, иначе ликвидация судом) |
| Привилегированные акции | ≤ 25% УФ |
| Имущественные права как вклад | ≤ 50% УФ |
| СД обязателен | > 50 акционеров; > 1000 → ≥ 7 членов; > 10 000 → ≥ 9 |
| Кумулятивное голосование | > 100 акц. — «следует», если устав не иное; > 1000 — только кумулятивно |
| Только бюллетени, счетная комиссия (≥ 3 чел.) | > 100 владельцев голосующих акций |
| Годовое ОС | не позднее 3 мес. после окончания года |
| Извещение | годовое ≥ 30 дн.; внеочередное ≥ 10; выборы органов ≥ 20; кумулятивное ≥ 50; повторное ≥ 10 |
| Кворум | > 50%; повторное > 30% |
| Созыв по требованию | акционеры ≥ 10% голосов, ревизионная комиссия, иной орган управления |
| Дивиденды | за квартал, полугодие, 9 мес., год; срок выплаты ≤ 60 дней (если не определен) |
| Приобретение своих акций | срок 30 дн. — 6 мес.; реализовать за 1 год |
| Крупная сделка | ≥ 20% активов: 20–50% → 2/3; ≥ 50% → 3/4; в СД — единогласно |
| Заинтересованность в сделке | аффилированные с 20%+ в контрагенте; СД — при сделке ≤ 2% активов (если устав) |

## Решения и органы

- **Учредительное собрание** — только **очно**. Единогласно: оценка неденежных вкладов, устав, выпуск акций; органы — 3/4. Голоса учредителей — пропорционально распределяемым акциям (вне зависимости от категории).
- **Органы управления:** ОС (высший), СД, исполнительный орган. **Контрольный:** ревизионная комиссия (ревизор).
- **Изменение повестки на ОС** — только единогласно при участии всех имеющих право (если устав не иное), ст. 44 ЗХО.
- **Формы ОС:** очная, заочная, смешанная (ст. 42). Дистанционное участие — если предусмотрено **уставом** (единогласия не требуется).
- **Формы голосования:** открытое, карточками, бюллетенями.
- **Кумулятивное голосование:** голоса × число **избираемых мест** (не кандидатов).
- **СД:** только физлица; не более 1 члена коллегиального исп. органа; единоличный исп. орган — не член СД; председателя избирают члены СД; 1 член = 1 голос; при равенстве — голос председателя; передача голоса запрещена.
- **Исключительная компетенция ОС:** устав, размер УФ, образование органов, избрание СД и ревизионной комиссии, годовой отчет, реорганизация, ликвидация и др. Приобретение акций для маркет-мейкинга — СД (если устав).
- **Безвозмездная помощь:** ОС; СД; исп. орган — если передано уставом (ежеквартальный отчет).

## Права по акциям

- **Привилегированные:** фиксированный дивиденд и ликвидационная стоимость; голос — реорганизация, ликвидация, изменение вида, изменения устава, ограничивающие их права; при невыплате дивидендов — по всем вопросам до полной выплаты.
- **Солидарная ответственность** — акционеры, не полностью оплатившие акции (в пределах неоплаченной части).
- Солидарная (ст. 304 ГК) — кредитор вправе требовать с любого; субсидиарная (ст. 370 ГК) — сначала к основному должнику.
- Преимущественное право на **доп. выпуск** — может быть предусмотрено уставом.
- Ограничение числа акций у одного акционера — законодательными актами или уставом.

## Уставный фонд

- Увеличение: доп. выпуск (собственный капитал, средства акционеров, третьих лиц, зачет денежных требований) или рост номинала (собственный капитал; за счет средств акционеров — **единогласно**). Только после полной оплаты УФ.
- Изменение УФ — исключительная компетенция ОС, ≥ 3/4.
- Вклады в имущество без увеличения УФ — ст. 29-1 ЗХО.
- **Консолидация / дробление** — меняется количество акций без изменения УФ; нельзя менять число акционеров, соотношение долей, создавать дробные акции.

## Запреты

**Не вправе приобретать свои акции:** УФ не оплачен; устойчивая неплатежеспособность; ЧА < УФ + резервные; продавец — единственный участник; не завершен выкуп по ст. 78.  
**Не вправе объявлять/выплачивать дивиденды:** УФ не оплачен; ЧА < УФ + резервные; неплатежеспособность; не завершен выкуп по ст. 78. После отпадения — выплатить ≤ 60 дней.

## Выкуп по требованию (ст. 78) и реорганизация

- Выкуп: реорганизация, изменения устава с ограничением прав, крупная сделка, изменение вида. Требуют голосовавшие против / не извещенные.
- **Преобразование АО:** ООО, ОДО, хоз. товарищество, производственный кооператив; в УП — если один участник. **ОАО↔ЗАО — изменение вида, не преобразование** (3/4).
- Ликвидация — ОС, суд, регистрирующий орган.

## Не путать

| | |
|--|--|
| Изменение вида АО | Реорганизация в форме преобразования |
| Консолидация акций | Объединение ЦБ при ДУ |
| Независимый директор (не аффилирован) | Член СД — не акционер |
