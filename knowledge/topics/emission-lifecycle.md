# Жизненный цикл эмиссионных ценных бумаг

**Разделы книги:** программа B §10 «Эмиссия ценных бумаг» (огл. стр. 269); депозитарий — реестр (~печ. 122).  
**См. также:** `depositary.md`, `deals-registration.md`, `corporate-governance.md`.

## Ось времени (сжато)

```
Решение → [проспект] → госрегистрация выпуска
        → РАЗМЕЩЕНИЕ (первые владельцы)
        → ОБРАЩЕНИЕ (вторичный рынок)
        ↔ формирование РЕЕСТРА владельцев (по запросу / по закону; идёт по ходу жизни выпуска)
        → ПОГАШЕНИЕ (облигации; досрочное — возможно)
        → АННУЛИРОВАНИЕ (исключение выпуска из Госреестра ЦБ)
```

## Когда что происходит

| Этап | Суть | Когда |
|------|------|--------|
| **Размещение** | Сделки/действия → право у **первого** владельца; передача ЦБ первым владельцам. **Не** является обращением (ст. 1, 18 ЗОРЦБ) | После госрегистрации (регистрации) выпуска; в срок по решению/проспекту |
| **Обращение** | Сделки/действия → переход прав от **первого или последующего** владельца к другому (ст. 1 ЗОРЦБ) | После размещения; пока выпуск не погашен/не аннулирован |
| **Реестр владельцев** | Свод сведений о владельцах **именных** эмиссионных ЦБ; формирует **депозитарий эмитента** на дату по требованию эмитента / в иных случаях закона (ст. 1 ЗОРЦБ; обязанность депозитария) | Не «один раз в конце»: **на нужную дату** в период существования выпуска (после появления владельцев на счетах «депо») |
| **Погашение** | Исполнение обязательств эмитента по облигациям (в т.ч. досрочное) | По окончании срока / досрочно; для акций «погашения» как у облигаций нет |
| **Аннулирование** | Исключение выпуска из **Государственного реестра ценных бумаг** (ст. 14 ЗОРЦБ) | После погашения выпуска облигаций; ликвидация/реорганизация АО (акции); признание выпуска недействительным и др. **Часть выпуска** — уменьшение количества в Госреестре (не полное исключение) |

## Этапы процедуры эмиссии (до размещения)

Ст. 12 ЗОРЦБ (если иное не установлено):

1. принятие решения о выпуске (доп. выпуске);  
2. регистрация проспекта (облигации; акции открытой подпиской/продажей);  
3. государственная регистрация выпуска (или регистрация биржей/иной уполномоченной организацией);  
4. **размещение**.

Без регистрации выпуска размещение, как правило, **не допускается**.

## Не путать

| Понятие | Не смешивать с |
|---------|----------------|
| Размещение | Обращение (первые vs последующие владельцы) |
| Реестр владельцев ЦБ | Государственный реестр ценных бумаг (учёт **выпусков**) |
| Погашение облигаций | Аннулирование (погашение → основание для аннулирования выпуска) |
| Аннулирование **части** выпуска | Полное аннулирование выпуска |

## Типичный вопрос экзамена

> Когда размещение, обращение, реестр, погашение, аннулирование?

**Ответ-каркас:** размещение — после регистрации выпуска, первые владельцы; обращение — вторичный рынок; реестр — депозитарий эмитента на дату в период жизни выпуска; погашение — облигации; аннулирование — исключение из Госреестра ЦБ (часто после погашения / ликвидации АО).
