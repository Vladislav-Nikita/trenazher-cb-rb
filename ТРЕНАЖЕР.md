# Тренажёр к аттестату специалиста рынка ЦБ (РБ)

Краткая шпаргалка. Полная инструкция — в [README.md](README.md).

## Инициализация и запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\init.ps1 -Start
```

Только установка зависимостей (без запуска):

```powershell
powershell -ExecutionPolicy Bypass -File .\init.ps1
```

## Режимы

- **Тренировка** — сразу верно/неверно, пояснение и источник
- **Экзамен** — без подсказок, в конце % и отметка ≥80% «сдано»
- **Работа над ошибками** — вопросы, где хотя бы раз ошибались
- **Слабые темы** — приоритет вопросов с низкой долей правильных ответов

Прогресс: `data/progress.json` (сброс в сайдбаре).

На телефоне: кнопки выбора, **Ответить** / **Далее**, **← →** и сетка номеров.

На ПК дополнительно: `←` `→` навигация, `1`–`4` выбор, `Enter` — ответ / далее, `Esc` — меню.

## Тесты

```powershell
powershell -ExecutionPolicy Bypass -File .\init.ps1 -Test
```

## Важно

- Приложение **не изменяет** исходные JSON.
- Скрипты `scripts/render_review.py` и `scripts/shuffle_options.py` работают как раньше.
