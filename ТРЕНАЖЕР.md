# Тренажёр к аттестату специалиста рынка ЦБ (РБ)

Локальное приложение на Streamlit поверх банка `questions/d*.json`.

## Запуск

В PowerShell из корня этой папки:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Откроется браузер с тренажёром. Новые файлы `questions/d*.json` подхватываются при перезапуске (кэш Streamlit: обновите страницу или перезапустите процесс).

## Режимы

- **Тренировка** — сразу верно/неверно, пояснение и источник
- **Экзамен** — без подсказок, в конце % и отметка ≥80% «сдано»
- **Работа над ошибками** — вопросы, где хотя бы раз ошибались
- **Слабые темы** — приоритет вопросов с низкой долей правильных ответов

Прогресс хранится в `data/progress.json` (сброс — кнопка в сайдбаре).

## Тесты

```powershell
pytest
```

## Важно

- Приложение **не изменяет** исходные JSON.
- Скрипты `scripts/render_review.py` и `scripts/shuffle_options.py` работают как раньше.
- `questions/review/` не используется тренажёром.
